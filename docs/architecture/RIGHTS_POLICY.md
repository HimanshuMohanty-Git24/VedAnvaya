# Rights policy

VedaGraph has no corpus-wide license. Rights attach to each source file, translation, text
transcription, image, recording, or other asset. Website accessibility does not grant reuse.

The controlled statuses are `PUBLIC_DOMAIN`, `CC_BY`, `CC_BY_SA`, `CC_BY_NC`, `CC_BY_NC_SA`,
`PERMISSION_GRANTED`, `PERMISSION_REQUIRED`, `RESEARCH_ONLY`, `REFERENCE_ONLY`,
`EXTERNAL_REFERENCE_ONLY`, and `UNKNOWN`.

Operational defaults:

- `UNKNOWN` and `PERMISSION_REQUIRED`: do not redistribute or bulk ingest.
- `REFERENCE_ONLY` and `EXTERNAL_REFERENCE_ONLY`: store metadata/links, not copied media.
- Creative Commons: record exact version, attribution, holder, and source file.
- Public domain: still retain translator, edition, year, scan/transcription, and revision.
- Permission: record the written grant at asset granularity before changing status.

VHP's current copyright policy says its content cannot be reproduced partially or fully without
written permission from IGNCA or the contributor. D1 therefore uses VHP only for a local bounded
verification pilot and external media metadata; no recording is downloaded.

The reviewed GRETIL Rigveda TEI file declares CC BY-NC-SA 4.0 in its own TEI header. That finding
does not establish a license for other GRETIL files. It is registered at exact artifact/checksum
level and used only as a labelled candidate text in the generated, Git-ignored D2 sample. Any
redistributed derivative must remain non-commercial, provide attribution, and satisfy share-alike.

VedaWeb's public repository says each source file has a specific Creative Commons licence in its
TEI header. No VedaWeb text is ingested until the exact selected Book 1 artifact and header have
been reviewed and registered; repository visibility is not treated as corpus-wide permission.

The underlying 1896 Griffith Rigveda translation is marked public domain by Wikisource. Page
revision provenance must still be retained because the hosted transcription layer can change.

Repository source-code licensing is undecided, so no `LICENSE` file is included. Select a code
license separately from corpus-data and asset licensing.
