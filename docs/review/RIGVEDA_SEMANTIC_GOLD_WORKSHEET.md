# Rigveda semantic gold worksheet

This is a human annotation worksheet, not a gold label file generated by Luna.
The 120 rows remain `UNANNOTATED` until a person completes and signs them. The
worksheet carries identifiers and deterministic metadata only; source text stays
in the local EvidencePackets.

## Reviewer instructions

Review only claims supported by the supplied packet. For each proposed entity mark
`ACCEPT`, `REJECT`, or `MODIFY`; for each predicate do the same. Mark explicitness
as `EXPLICIT`, `STRONG_INFERENCE`, or `INTERPRETIVE`, and evidence as `VALID` or
`INVALID`. Optionally record a missing expected relation. Do not infer a relation
from traditional assignment alone, and do not use this worksheet to create an
exhaustive philosophical reading.

Allowed predicate slots: ASSOCIATED_WITH, CONTRASTS_WITH, DESCRIBES, DESCRIBES_ACTION, EXPRESSES, HAS_THEME, INVOKES, INVOLVES_OFFERING, INVOLVES_RITUAL, INVOLVES_SUBSTANCE, PRAISES, REFERS_TO_NATURAL_PHENOMENON, REFERS_TO_PLACE, REQUESTS.
Allowed semantic node types: CONCEPT, PHILOSOPHICAL_CONCEPT, THEME, RITUAL, OFFERING, SUBSTANCE, PLANT, ANIMAL, OBJECT, PLACE, RIVER, REGION, NATURAL_PHENOMENON, COSMIC_ENTITY, ACTION, QUALITY, STATE.
